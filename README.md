# Tyander
Tinder-like SPA for dating and chating with anime characters
## Features
⚠️The project is under development and some functions may be unstable⚠️
## Languages and tools
* Typescript as programming language
* SASS as CSS-preprocessor
* React as library for building a UI
  * motion for animations
  * material-ui for icons
* MobX for state management
* Vite as module bundler
* axios for HTTP requests
* nekos.best as API for images
* faker.api as API for fake data
